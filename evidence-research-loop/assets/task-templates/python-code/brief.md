# Python code optimization task

Implement `solve(values)` in `candidate.py`.

- Input: a Python list of integers.
- Output: the unique integers in ascending order as a Python list.
- Preserve the function name and one-argument interface.
- Use only the Python standard library.
- Correctness on every evaluator case is a hard gate.
- Among correct candidates, minimize median execution time and then p95 execution time.

The evaluator, its cases, and holdout data are intentionally absent from the generator workspace.
