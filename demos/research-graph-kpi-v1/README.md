# Research Graph KPI collaboration demo

This directory records a real four-node, multi-Agent Research Graph run. Two
independent ready nodes define a KPI metric contract and adversarial cases. A
third Agent receives only their verified direct dependency assets and writes the
calculator. A fourth Agent records root integration evidence.

The verifier checks artifacts rather than awarding a preset score. This demo
tests orchestration, dependency exposure, node verification, provenance, and
root acceptance. It does not prove that every KPI policy is fair, suitable for
employment decisions, or production ready.

## Actual run result

- Four graph nodes reached `verified`; the root goal reached `accepted: true`.
- Final audit: `valid: true`, `accepted: true`, 17 graph events, 5 contribution
  records, and 4 reusable verified assets.
- The first integration attempt (`attempt-f94af4c7daeb4254b869c3e9582488ef`)
  failed because it encoded `dependency_assets` as an array. The failed attempt
  remains immutable. Revision 2 reopened only that node; the repaired attempt
  (`attempt-7a5448ebf28f4b569f41dcdc84b0cde4`) passed all 7 independent calculator
  checks and produced `asset-ae0efac4bddadeb6f9a4`.
- The four artifacts were generated by four separate Codex Agent turns. Their
  provider-side token cost is not available in this run, so no dollar-cost
  claim is made.
