# Scientist Mode 结构冒烟测试

目标是检查 Evidence Research Loop 能否执行、选择、冻结并复算一个包含五个可选模块的预设工作流：

1. `ideation`：从初始方向产生多个可检验假设；
2. `literature`：根据冻结文献语料排除已知假设并保留引用依据；
3. `tree_manager`：在失败分支后继续扩展实验树并管理预算；
4. `analysis`：聚合多次实验结果、处理异常值并生成受证据支持的结论；
5. `paper_review`：形成结构化研究包并在交付前拒绝无证据主张。

候选是只包含以上五个布尔字段的 JSON。固定模拟器按预设规则执行候选工作流，记录假设标签、分支状态、结论标签、研究包标签和阶段成本。

测试分数由裁判直接定义：关闭某些模块会按设计失去对应结构覆盖。因此，候选差值不能解释为模块贡献或必要性，seed 重复也不能验证规则本身。`hard-pass` 仅检查配置格式和记录数量。本测试不检验真实模型的科学创造力、现实文献新颖性、实验有效性或论文质量。
